# راهنمای مدیر سیستم و مدیر مدرسه

## ۱) مدیر کل (راه‌اندازی)
1. نصب و مهاجرت: `php artisan migrate --force && php artisan rbac:sync`.
2. ساخت اولین مدیر کل: `php artisan platform:create-admin you@example.com` (رمز تعاملی).
3. تنظیمات سرویس‌ها در `.env` (S3، LiveKit/TURN، Reverb، FCM، AI) — سرویس تنظیم‌نشده در «سلامت سرویس‌ها» با برچسب «پیکربندی نشده» دیده می‌شود.
4. پنل مدیر کل: درخواست‌های مدرسه (تأیید/رد/نیاز به اصلاح)، مدارس (تعلیق، اشتراک و سقف‌ها)، اعلان سراسری، مدیران و پشتیبان‌ها، گزارش عملیات، تنظیمات (بستن ثبت‌نام عمومی).
5. پایش: «نمای کلی» شامل مصرف منابع هر مدرسه، سلامت سرویس‌ها و **عملکرد API** (درخواست، میانگین تأخیر، خطای ۵xx، کندترین مسیرها، صف). آستانهٔ هشدار: خطای ۵xx غیرصفر یا `failed_jobs` غیرصفر را بررسی کنید.

## ۲) مدیر مدرسه (شروع کار)
ترتیب پیشنهادی: **سال تحصیلی → ترم → پایه → درس → کلاس → معلم → تخصیص معلم → دانش‌آموزان (یا ورود گروهی CSV/XLSX) → والدین → برنامهٔ هفتگی → فعال‌سازی**.
- فعال‌سازی برنامه همه را آگاه می‌کند؛ نسخهٔ قبلی بایگانی می‌شود.
- تقویم: تعطیلی «لغو کلاس‌ها» زنگ آن روز را متوقف می‌کند. جایگزین/لغو برای یک تاریخ در برنامهٔ هفتگی.
- نمرات: معلم پیش‌نویس می‌دهد، مدیر/معاون تأیید می‌کند؛ فقط نمرهٔ تأییدشده در کارنامه و برای دانش‌آموز/والد دیده می‌شود. تغییر نمرهٔ تأییدشده دلیل می‌خواهد.
- کارنامه: قالب → تولید (فقط از نمرات تأییدشده) → صدور.
- **پایان سال:** کارنامه‌ها را صادر کنید، سال تحصیلی جدید و کلاس‌هایش را بسازید، سپس «ثبت‌نام و انتقال ← ارتقای کلاس» (گزینهٔ «فقط قبول‌شده‌ها»). دانش‌آموزان ردشده در کلاس قبلی می‌مانند و پرونده‌شان حفظ می‌شود.
- پرونده تحصیلی هر دانش‌آموز از «کاربران ← دانش‌آموزان ← پرونده».
- درخواست حذف اطلاعات: همان‌جا «حذف اطلاعات هویتی» (برگشت‌ناپذیر).
- دسترسی پشتیبان فنی: تنظیمات ← پشتیبانی؛ زمان‌دار و فقط‌خواندنی.
