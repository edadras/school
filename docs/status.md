# وضعیت پیاده‌سازی (صادقانه)

آخرین بروزرسانی: مرحله ۱. «انجام‌شده» یعنی کد + تست خودکار اجراشده. «زیرساخت/Adapter» یعنی رابط واقعی هست ولی سرویس بیرونی وصل نشده.

## انجام‌شده و آزمایش‌شده (۳۷ تست، SQLite)
- احراز هویت: ورود، خروج، نشست‌های توکنی با انقضا (Sanctum)، بازیابی رمز، Rate-limit ورود (هم per-login هم per-IP)، پاسخ یکسان برای کاربر ناموجود/رمز غلط.
- Multi-Tenant: `school_id` در همهٔ جداول، Global Scope «بسته‌به‌صورت‌پیش‌فرض»، تعیین مدرسه فقط از عضویت تأییدشدهٔ سرور (هدر `X-School-Id` فقط انتخاب‌گر است)، `school_id` غیرقابل‌تغییر و غیرقابل mass-assign، قواعد `exists` محدود به مدرسه.
- چرخهٔ فعال‌سازی: ثبت‌نام → pending → تأیید/رد/نیاز به اصلاح (+ ارسال مجدد) → active؛ تعلیق/فعال‌سازی مجدد؛ قفل خوش‌بینانه برای تصمیم دوباره؛ Audit.
- RBAC: نقش/مجوز در DB (sync از `config/rbac.php`)، middleware `perm:`، نقش platform جدا.
- ساختار آموزشی: سال، پایه، درس، کلاس، معلم، دانش‌آموز، تقویم، تخصیص معلم (تداخل)، ثبت‌نام/انتقال با ظرفیت (قفل ردیف)، والد با پیوند تأییدشده، سقف اشتراک (دانش‌آموز/معلم).
- برنامهٔ هفتگی: ساخت زنگ‌ها (هم‌پوشانی/معکوس رد می‌شود)، تشخیص تداخل کلاس/معلم/روز غیرکاری/عدم‌تخصیص قبل از ذخیره (`/check`) + قید یکتای DB، نسخه‌بندی و بایگانی، جایگزین/لغو در یک تاریخ.
- موتور زنگ: رویدادها با زمان سرور و منطقهٔ زمانی مدرسه، تولید و اجرای idempotent (کلید یکتا + dedupe اعلان)، بازیابی پس از Restart (۱۰ دقیقه جبران، قدیمی‌تر بی‌صدا بسته می‌شود)، تعطیلات، جایگزین/لغو، همگام‌سازی با `since_id`.
- Audit Log فقط‌افزودنی.

## هنوز ساخته نشده (برنامهٔ مراحل بعد)
| بخش | وضعیت |
|---|---|
| Flutter (همهٔ پنل‌ها) | **ساخته نشده** — SDK فلاتر در این محیط نبود؛ کد تست‌نشده تحویل نمی‌دهیم. API قرارداد آماده است. |
| کلاس آنلاین (WebRTC/SFU/TURN) | ساخته نشده. طراحی Adapter: `docs/realtime-and-media.md` |
| WebSocket/Push/ایمیل | outbox آماده؛ کانال‌های Reverb/FCM/WebPush ساخته نشده |
| پیام‌رسان، تکلیف، آزمون، نمره‌دهی، کارنامه PDF، پنل والد (UI) | ساخته نشده (جداول طراحی‌شده در ERD) |
| AI | ساخته نشده (طراحی Adapter در معماری) |
| ورود گروهی Excel/CSV، ذخیره فایل S3 | ساخته نشده |
| MySQL | Migrationها فقط روی SQLite تست شدند؛ سرور MySQL در این محیط نبود |
| Docker | فایل‌ها نوشته شد ولی اجرا نشد (daemon در دسترس نبود) |
| تست بار / ظرفیت | اجرا نشده؛ هیچ عدد ظرفیتی ادعا نمی‌شود |
