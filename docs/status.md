# وضعیت پیاده‌سازی (صادقانه)

«انجام‌شده» یعنی کد + تست خودکار اجراشده. هر چه اجرا یا آزموده نشده، صراحتاً در بخش «آزموده‌نشده» آمده است.

## ارقام تست (اجرای نهایی)
| مجموعه | نتیجه |
|---|---|
| Backend (PHPUnit) | **۱۲۴ تست / ۸۹۸ assertion** سبز — SQLite و **MariaDB 10.11** |
| E2E (Playwright، مرورگر واقعی روی پشتهٔ واقعی) | **۲۸ تست سبز** در یک اجرای کامل (۷٫۳ دقیقه) |
| تست بار | اجرا و اندازه‌گیری شد (فقط خواندنی‌های REST؛ `docs/operations.md`) |
| `composer audit` | بدون هشدار |

پشتهٔ E2E: MariaDB، Redis، Reverb، صف، Scheduler، **LiveKit SFU واقعی**، بیلد وب Flutter، Chromium با دوربین/میکروفون ساختگی (`scripts/e2e-stack.sh`).

## قابلیت‌های ساخته‌شده
- **پایه:** Multi-Tenant fail-closed، RBAC (۲۸ مجوز، ۵ نقش مدرسه + ۲ نقش پلتفرم)، دسترسی سطری، ثبت‌نام→تأیید→فعال‌سازی، تعلیق، اشتراک و سقف‌ها، دسترسی زمان‌دار پشتیبان، Audit فقط‌افزودنی. دروازهٔ `registration_open` در تنظیمات پلتفرم اعمال می‌شود.
- **ساختار آموزشی:** سال/ترم/پایه/درس/کلاس/معلم/دانش‌آموز/والد/ثبت‌نام و انتقال، ورود گروهی CSV/XLSX و خروجی داده، ساخت حساب برای دانش‌آموز/والد/معاون.
- **برنامه و زنگ:** برنامهٔ هفتگی نسخه‌دار با تشخیص تداخل، جایگزین/لغو، تقویم و تعطیلات، موتور زنگ ایدمپوتنت با زمان سرور، بسته‌شدن خودکار کلاس‌های ماندهٔ بیش از ۲۰ دقیقه، «برگزار نشد».
- **کلاس زنده:** LiveKit (SFU) + Null adapter، توکن کوتاه‌عمر، میزبانی فقط معلم تخصیص‌یافته، بی‌صدا/حذف، دست‌بالابردن، وایت‌برد، گزارش مشکل، حضور و غیاب خودکار + اصلاح دستی.
- **پیام‌رسان:** گفت‌وگوی کلاس و مستقیم با سیاست مدرسه، پیوست، گزارش پیام و مدیریت، Realtime با fallback.
- **یادگیری:** مطالب (متن/لینک/فایل)، تکلیف (متن/فایل/فرمول/صدا، روبریک، بازگرداندن برای اصلاح، نسخه‌ها)، آزمون (بانک سؤال، ترتیب تصادفی، زمان‌دار، تصحیح خودکار/دستی، انتشار نتیجه، تحلیل).
- **نمره و کارنامه:** پیش‌نویس/تأیید، فرمول قابل‌تنظیم، قالب، صدور/ابطال، PDF فارسی.
- **اعلان‌ها:** realtime + FCM v1 + ایمیل با ترجیحات کاربر، outbox ایدمپوتنت.
- **AI:** Adapter قابل‌تعویض، ناشناس‌ساز، منبع قابل‌نمایش، بودجه، فقط مشورتی (دستیار دانش‌آموز/معلم/مدیر، گفتار↔متن در صورت پیکربندی).
- **پنل‌ها (Flutter):** مدیر کل، مدیر مدرسه/معاون، معلم، دانش‌آموز، والد، پشتیبان — واکنش‌گرا و RTL.
- **پرونده تحصیلی پیوسته** (سوابق ثبت‌نام/ارتقا، نمرات تأییدشده هر دوره، کارنامه‌ها، حضور، تکالیف، یادداشت‌ها)، **ارتقای دسته‌جمعی کلاس** به سال بعد (فقط قبول‌شده‌ها، کنترل ظرفیت، idempotent)، **ناشناس‌سازی دانش‌آموز** با تأیید کد.
- **پایش API:** شمارنده‌های درخواست/خطا/تأخیر در Redis، نمایش در داشبورد مدیر کل.
- **پویشگر ویروس ClamAV** (آزموده‌شده با clamd واقعی)، **2FA/TOTP** با کد بازیابی و سیاست اجباری، **نگهداری داده** (job روزانه با سیاست هر مدرسه)، **ضبط کلاس** (Egress، فقط‌میزبان/مدیر).
- **OpenAPI** تولیدشده از جدول مسیرها (۱۸۹ عملیات).

## آزموده‌نشده یا ساخته‌نشده (صادقانه)
| مورد | وضعیت |
|---|---|
| **اپ اندروید** | **APK ساخته شد** (release، minSdk 24، targetSdk 36، ۱۰۲MB، امضای debug) و مانیفست/دسترسی‌ها بررسی شد؛ **روی دستگاه یا شبیه‌ساز اجرا نشد** (KVM نبود). آزمون‌های رفتاری فقط روی وب است. |
| **Push واقعی (FCM)** | Adapter کامل است؛ بدون پروژهٔ Firebase آزموده نشد. بدون پیکربندی، تحویل «unconfigured» گزارش می‌شود. |
| **TURN (coturn)** و NAT/فایروال واقعی | فقط پیکربندی و تولید اعتبار؛ تست اتصال عملی نشد. |
| **MySQL 8.4** | آزمون روی **MariaDB 10.11** و SQLite انجام شد؛ MySQL 8.4 اجرا نشد. |
| **Docker** | `infra/*` نوشته شد و فقط نحو YAML بررسی شد ولی **اجرا نشد** (daemon نبود). |
| **ارائه‌دهندهٔ واقعی AI** | بدون کلید آزموده نشد. |
| **تست بار WebRTC/WebSocket و ظرفیت هم‌زمانی کاربر** | اجرا نشده؛ **هیچ عدد ظرفیتی ادعا نمی‌شود.** |
| **iOS/APNs، تست نفوذ مستقل، 2FA غیر از TOTP** | ساخته/اجرا نشده (`docs/security-privacy.md`) |
| **ضبط کلاس با Egress واقعی** | کد، سیاست‌ها، وبهوک و دسترسی ساخته و تست خودکار شد؛ **سرویس livekit-egress در محیط توسعه اجرا نشد**، پس ضبط واقعی دیده نشده است |
| **بازیابی پشتیبان** | روش مستند شد؛ هرگز آزموده نشد. |
| **حالت آفلاین کامل (PWA/کش)** | ساخته نشده؛ فقط ذخیرهٔ پاسخ آزمون و همگام‌سازی پس از وصل شدن آزموده شد. |

## یافته‌ها و اصلاحات حین تست نهایی
- زنگ پایان درس برای جلسه‌ای که هرگز وارد SFU نشده بود، روی ۴۰۴ اتاق می‌ماند و رویداد را برای همیشه بدون پردازش نگه می‌داشت → اصلاح (۴۰۴ اتاق = پایان‌یافته؛ شکست یک رویداد بقیه را متوقف نمی‌کند) + تست رگرسیون.
- درخواست بدون `Accept: application/json` و بدون توکن ۵۰۰ می‌داد → ۴۰۱ JSON + هدرهای امنیتی روی خطاها + تست.
- `.env.example` کلیدهای تکراری داشت (اولین مقدار برنده می‌شد: `BROADCAST_CONNECTION=log`) → یکتا شد.
- CORS پیش‌فرض `*` بود → پیش‌فرض بسته.
- مسیرهای push‌شده (آزمون/کلاس) آدرس خود را نداشتند و refresh به لیست برمی‌گشت → آدرس منعکس می‌شود و refresh همان آزمون را ادامه می‌دهد.
