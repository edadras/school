# امنیت و حریم خصوصی

## پیاده‌شده و آزمایش‌شده
- **جداسازی مدارس:** Tenant fail-closed، `school_id` غیرقابل‌تغییر و غیر mass-assignable، قواعد `exists` محدود به مدرسه، کانال‌های WebSocket خصوصی با مجوز سمت سرور. تست‌های خودکار: دسترسی به شناسهٔ مدرسهٔ دیگر ⇒ 404؛ E2E: دو مدرسه در یک پایگاه‌داده.
- **دسترسی سطری:** معلم فقط کلاس‌های خودش (حتی با شناختن شناسه)، دانش‌آموز فقط خودش، والد فقط فرزند تأییدشده؛ داده‌های تماس معلم برای غیرکارکنان پنهان است.
- **احراز هویت:** Bcrypt، حداقل ۱۰ نویسه، توکن ۱۴ روزه، ابطال همهٔ توکن‌ها پس از بازیابی رمز، پاسخ یکسان برای کاربر ناموجود/رمز غلط/غیرفعال، Rate-limit ورود (۵ در دقیقه به‌ازای login+IP)، بازیابی رمز (۶/دقیقه)، ثبت‌نام مدرسه (قابل تنظیم، پیش‌فرض ۵ در ساعت به‌ازای IP).
- **خطاهای احراز هویت:** درخواست بدون توکن همیشه JSON 401 است (یافتهٔ بازبینی: بدون هدر `Accept` پیش‌تر 500 می‌داد؛ اصلاح و با تست پوشش داده شد). هدرهای `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Cache-Control: no-store` روی پاسخ‌های موفق و خطا.
- **CORS:** پیش‌فرض هیچ origin خارجی مجاز نیست (`CORS_ALLOWED_ORIGINS` خالی)؛ در تولید فقط origin وب‌اپ.
- **فایل‌ها:** نوع از بایت‌های واقعی (`finfo`) نه از کلاینت، فهرست سفید، سقف حجم، ذخیرهٔ خصوصی، دانلود فقط با لینک امضاشدهٔ ۵ دقیقه‌ای، فایل‌های غیرقابل‌نمایش اجباراً دانلود می‌شوند، ثبت SHA-256.
- **آزمون:** کلید پاسخ هرگز برای دانش‌آموز ارسال نمی‌شود؛ پاسخ صحیح قبل از پایان آزمون نمایش داده نمی‌شود؛ مهلت را سرور تعیین می‌کند؛ نتیجه فقط با انتشار معلم/مدیر دیده می‌شود.
- **نمره و کارنامه:** نمرهٔ پیش‌نویس برای دانش‌آموز/والد نامرئی است؛ کارنامه فقط از نمرات تأییدشده؛ تغییر نمرهٔ تأییدشده نیازمند دلیل + مجوز و تاریخچه؛ PDF فقط برای نشست مجاز، `no-store`.
- **پشتیبان فنی:** پیش‌فرض بدون دسترسی؛ مدیر مدرسه دسترسی زمان‌دار صادر می‌کند؛ فقط GET و فهرست سفیدِ مسیرهای ساختاری (بدون نمره/پیام/آزمون/فایل)؛ همه Audit می‌شوند.
- **AI:** فقط مشورتی؛ ناشناس‌ساز قبل از ارسال به ارائه‌دهنده؛ منبع پاسخ قابل نمایش؛ بودجهٔ روزانهٔ کاربر و مدرسه؛ هیچ نمره/تصمیمی خودکار ثبت نمی‌شود.
- **Audit فقط‌افزودنی:** تأیید/رد/تعلیق مدرسه، ورود مدیران، تغییر نمره، دسترسی پشتیبان، مشاهدهٔ PDF کارنامه، تغییر برنامه/اشتراک، پیوند والد.
- **زنجیرهٔ تأمین:** `composer audit` بدون هشدار (در زمان تحویل).

## یافته‌های بازبینی که اصلاح شدند
| یافته | اصلاح |
|---|---|
| معلم با شناختن شناسه‌ها می‌توانست دانش‌آموزان/کلاس‌ها/تکالیف همهٔ مدرسه را فهرست کند | `scoped()` روی منابع + تست |
| مدیر مدرسه می‌توانست میزبان جلسه شود | فقط معلم تخصیص‌یافته میزبان است؛ مدیر ناظر است |
| معاون نمی‌توانست نمره را تأیید/اصلاح کند | مجوز `grades.approve` روی مسیر |
| 500 به‌جای 401 بدون `Accept: application/json` | `redirectGuestsTo(null)` + تست |
| CORS پیش‌فرض `*` | پیش‌فرض خالی |
| بستن کلاس بدون اتاق در SFU، زنگ را برای همیشه قفل می‌کرد (دسترس‌پذیری) | 404 اتاق = «پایان‌یافته»؛ شکست یک رویداد بقیه را متوقف نمی‌کند + تست |

## افزوده‌شده در این مرحله
- **پویشگر ویروس فایل (ClamAV):** هر بارگذاری از طریق پروتکل `INSTREAM` به `clamd` فرستاده می‌شود؛ فایل آلوده رد (۴۲۲) و در Audit ثبت می‌شود و هیچ اثری روی دیسک نمی‌ماند. اگر پویشگر پیکربندی شده ولی در دسترس نباشد، پیش‌فرض **fail-closed** است (۵۰۳)؛ با `SCAN_FAIL_CLOSED=false` فایل با `scan_status=error` پذیرفته می‌شود. بدون پیکربندی، وضعیت `skipped` ثبت و در سلامت سرویس‌ها «پیکربندی نشده» نشان داده می‌شود. **آزموده‌شده با clamd واقعی** (امضای EICAR) هم در PHPUnit هم در E2E.
- **احراز هویت دومرحله‌ای (TOTP، RFC 6238):** اپ Authenticator + ۱۰ کد بازیابی یک‌بارمصرف (هش‌شده)، جلوگیری از replay، ۵ تلاش برای هر چالش ورود، رمز TOTP رمزنگاری‌شده با کلید برنامه. سیاست پلتفرم «اجباری برای مدیران کل/پشتیبان/مدیر مدرسه» قابل فعال‌سازی است؛ تا فعال‌سازی، API فقط مسیرهای ثبت‌نام 2FA را باز می‌گذارد. آزموده‌شده با بردار رسمی RFC و در مرورگر واقعی.
- **ضبط کلاس:** دو سطح اجازه (سیاست مدرسه + روشن‌کردن توسط میزبان)، اطلاع بی‌درنگ و نوار «در حال ضبط» برای همهٔ شرکت‌کنندگان، پخش فقط برای میزبان و مدیران؛ فایل ضبط خصوصی و با لینک امضاشده. نیازمند سرویس Egress (جزئیات: `realtime-and-media.md`).
- **نگهداری داده:** job روزانهٔ `retention:run` طبق سیاست هر مدرسه (پیام‌ها، اعلان‌های خوانده‌شده، سابقهٔ AI، تخته سفید، تیکت‌های بسته؛ حداقل ۳۰ روز؛ پیش‌فرض نگهداری دائم) + پاک‌سازی همیشگی فایل‌های بی‌مصرف بالای ۷ روز. نمرات/کارنامه/ثبت‌نام/Audit هرگز حذف نمی‌شوند.

## انجام‌نشده / باید قبل از عرضه انجام شود
- **تست نفوذ مستقل** انجام نشده است؛ بازبینی بالا خودارزیابی توسعه‌دهنده است.
- **ضبط:** با سرویس Egress واقعی آزموده نشده است (فقط قرارداد HTTP آداپتر، سیاست‌ها، وبهوک و کنترل دسترسی با تست خودکار). برای اولین استقرار باید یک ضبط واقعی انجام و بررسی شود.
- **کنترل ارتباط بزرگسال–کودک** در پیام‌رسان: سیاست مدرسه (چه کسی با چه کسی) پیاده است؛ بازبینی محتوای خودکار نه.
- **بازبینی حقوقی** داده‌های کودکان و انتقال برون‌مرزی داده (به‌ویژه هنگام استفاده از ارائه‌دهندهٔ AI خارجی) باید توسط مشاور حقوقی بازار هدف انجام شود.
- 2FA با پیامک/ایمیل یا WebAuthn نیست (فقط TOTP).
- پایگاه امضای ClamAV باید با `freshclam` به‌روز نگه داشته شود (در محیط توسعه فقط یک امضای EICAR برای آزمون بود).
