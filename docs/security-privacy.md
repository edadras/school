# امنیت و حریم خصوصی

## پیاده‌شده
Tenant fail-closed · مجوز سمت سرور روی همهٔ مسیرها · Rate-limit ورود/ثبت‌نام · رمز Bcrypt + حداقل ۱۰ نویسه · توکن با انقضای ۱۴ روز و ابطال همهٔ توکن‌ها پس از بازیابی رمز · عدم افشای وجود حساب · `platform_role`/`status` غیر mass-assignable · هدرهای امنیتی و `Cache-Control: no-store` · Eloquent/Query Builder پارامتری (SQLi) · API توکنی بدون کوکی (CSRF بی‌اثر) · Audit فقط‌افزودنی (تأیید/رد/تعلیق مدرسه، ورود مدیران، تغییر برنامه/اشتراک/ثبت‌نام، پیوند والد).

## باید قبل از عرضه انجام شود
- ذخیرهٔ فایل خصوصی با S3 + لینک امضاشدهٔ کوتاه‌عمر (هنوز فایلی ذخیره نمی‌شود).
- بررسی نوع/حجم/ویروس فایل؛ سیاست نگهداری/حذف/خروجی داده؛ پشتیبان‌گیری و **آزمون بازیابی**.
- پشتیبان فنی: دسترسی موقت، با دلیل و Audit، برای داده‌های دانش‌آموز (طراحی، ساخته نشده).
- کنترل ارتباط بزرگسال–کودک در پیام‌رسان، رضایت‌نامهٔ ضبط/AI، حداقل‌سازی و ناشناس‌سازی داده برای AI.
- بازبینی حقوقی داده‌های کودکان و انتقال برون‌مرزی داده برای بازار هدف (ایران/ترکیه) — توسط مشاور حقوقی.
- Pentest مستقل و تست بار.
