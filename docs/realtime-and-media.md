# Realtime، زنگ و کلاس آنلاین

## صدای زنگ و محدودیت پلتفرم‌ها (مستند الزامی)
- **مرورگر/Flutter Web:** صدا فقط بعد از یک تعامل کاربر (autoplay policy) و تا وقتی تب باز است پخش می‌شود. تب پس‌زمینه ممکن است Timer را کند کند و تب بسته هیچ صدایی ندارد. راه‌حل: Web Push (Service Worker) برای نمایش اعلان، و درون‌برنامه صدا را با «زمان سرور − اختلاف ساعت» زمان‌بندی و با همگام‌سازی `since_id` جبران کنید.
- **اندروید:** برای تضمین صدا از FCM (data+notification با channel دارای صدا) استفاده کنید؛ Timer داخل اپ در Doze قابل اتکا نیست.
- **iOS:** فقط APNs؛ صدای سفارشی ≤ ۳۰ ثانیه.
- هیچ‌جا «صدای قطعی با بستهٔ کامل برنامه» وعده داده نمی‌شود.

## کانال‌های تحویل (طراحی)
`notifications_outbox` منبع حقیقت است. هر کانال (WebSocket/Reverb، FCM، WebPush، ایمیل) یک Job صف‌بندی‌شده است که ردیف‌های جدید را می‌خواند و وضعیت ارسال را ثبت می‌کند. کانال‌های خصوصی WebSocket باید `school.{id}.user.{id}` باشند و در `routes/channels.php` عضویت را با همان `ResolveSchool` اعتبارسنجی کنند.

## کلاس آنلاین (ساخته نشده — طراحی)
- رابط `MediaProvider` { `createRoom`, `joinToken(user, role)`, `muteParticipant`, `endRoom`, `health` } + پیاده‌سازی `LiveKitProvider` (SFU متن‌باز، همراه TURN داخلی/coturn).
- پیکربندی‌نشده (`MEDIA_PROVIDER=none`) ⇒ API پاسخ `503 {code: media_unconfigured}` می‌دهد و UI صراحتاً «پیکربندی نشده» نشان می‌دهد.
- توکن ورود کوتاه‌عمر، فقط برای دانش‌آموز ثبت‌نام‌شده در کلاس + زمان مجاز؛ ثبت ورود/خروج از webhook SFU.
- ظرفیت: سقف `school_subscriptions.max_live_sessions`؛ ظرفیت واقعی فقط پس از تست بار روی سخت‌افزار هدف تعیین می‌شود.
- ضبط: فقط با سیاست مدرسه + رضایت + اعلان به شرکت‌کنندگان.
